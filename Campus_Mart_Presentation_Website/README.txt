# CAMPUS MART — Presentation Website

A presentation-style website built with plain HTML, CSS and JavaScript.

## Run
1. Put `index.html`, `style.css` and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. Use the on-screen arrows, keyboard arrows, spacebar, or swipe on mobile.

## Theme
The visual direction is based on the supplied Campus Mart reference: warm orange/coral, off-white, pale aqua, and dark charcoal/navy. It intentionally avoids the black-and-gold theme mentioned initially.

## Edit the content
All slide copy is directly inside `index.html`.
Colors and layout are in `style.css`.
Slide navigation and transitions are in `script.js`.

## Important wording
The deck uses "pinpoint campus location" / "requested campus point" rather than promising GPS-level indoor accuracy. If the actual product supports precise coordinates, you can change that wording once the technical implementation is confirmed.
